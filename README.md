# VPS Bill 2.5.12

Telegram-first менеджер оплат и мониторинга VPS.

- Рабочая папка: `/opt/vps-bill`
- Конфиг запуска: `/opt/vps-bill/.env`
- База: `/opt/vps-bill/data/billing.db`
- Docker project / image / container: `vps-bill`

## Что нового в 2.5.12

- Premium emoji разбиты на страницы по 8 слотов.

## Первый переход на 2.5.9

Обновите VPS Bill обычной командой один раз:

```bash
vps-bill-update --file /opt/vps-bill-2.5.12.tar.gz
```

Updater 2.5.8 автоматически вызовет совместимый `install-auto-update.sh` из нового релиза; в 2.5.9 этот скрипт не ставит timer, а устанавливает безопасный update bridge.

Проверить bridge:

```bash
systemctl status vps-bill-update-request.path
```

После этого следующие релизы можно устанавливать из Telegram: `Настройки → Обновление`.

## Что должно быть в GitHub Release

Для версии `2.6.0` загрузите asset с точным именем:

```text
vps-bill-2.6.0.tar.gz
```

Рекомендуется также загрузить один из checksum-файлов:

```text
vps-bill-2.6.0.tar.gz.sha256
```

или:

```text
SHA256SUMS
```

Если GitHub API отдаёт `sha256` digest самого asset, bridge использует его автоматически.

## История изменений

См. `CHANGELOG.md`.

### Обновление с GitHub

После публикации GitHub Release достаточно запустить:

```bash
vps-bill-update
```

Updater сам определит последнюю версию, скачает `vps-bill-X.Y.Z.tar.gz`, проверит checksum если он опубликован и выполнит безопасное обновление. `docker compose pull` для VPS Bill не используется: image собирается локально из release-архива.

## Release notes и CHANGELOG

Единственный источник описания изменений — `CHANGELOG.md` в корне проекта. Для каждой версии должна существовать секция вида `## 2.5.14`. Telegram и GitHub Release используют только содержимое этой секции; autogenerated GitHub notes не используются.
