# VPS Bill

Telegram-бот для учёта VPS, расходов, дат оплаты и мониторинга доступности.

## Возможности

- учёт VPS, хостеров, стран, IP, тегов и заметок;
- стоимость, даты оплаты и история платежей;
- напоминания и аналитика расходов;
- мониторинг доступности серверов;
- backup / restore;
- обновления через GitHub Releases;
- установка обновлений из Telegram;
- опциональные демо-серверы при первой установке.

## Установка

```bash
bash <(curl -fsSL https://raw.githubusercontent.com/flu-ghsh/vps-bill/main/install.sh)
```

Установщик запросит Bot Token, Telegram ID, SOCKS5 при необходимости, timezone и предложит добавить демо-серверы.

После установки:

```text
/opt/vps-bill
```

## Команды

```bash
docker logs -f vps-bill
vps-bill-update
vps-bill-backup
vps-bill-restore
```

Текущая версия:

```bash
cat /opt/vps-bill/current/VERSION
```

## Данные

```text
База:     /opt/vps-bill/data/billing.db
Backups:  /opt/vps-bill/backups/
Config:   /opt/vps-bill/.env
```

## Обновление 2.5.33

- В карточке VPS с оплатой с баланса: **Данные → Стоимость за сутки**.
  Новая ставка применяется к будущим суткам; остаток баланса сохраняется.
- В последний день календарного месяца в истории появляется одна информационная
  запись расхода каждого активного ежедневного VPS с балансом. Реальные пополнения
  баланса остаются отдельными платежами; месячное начисление не входит в
  фактические суммы оплат, чтобы не учитывать расходы дважды.
- Для обычных VPS с ежедневной оплатой история показывает платежи за месяц одной
  строкой на последний день месяца. Исходные записи доступны в «Удаление платежей».
- **Настройки → Мониторинг → Проверить доступность сейчас** запускает Ping всех
  активных VPS и присылает общий результат в Telegram. Эта проверка не меняет
  состояние автоматического мониторинга; ICMP может блокироваться firewall.
- Учёт ставок для ранее созданных VPS с балансом начинается со дня установки
  версии 2.5.33: исторические цены до обновления автоматически не восстанавливаются.

Обновление существующей установки через локальный релиз:

```bash
vps-bill-update --file /opt/vps-bill-2.5.33.tar.gz
```


## Проверка установленной версии 2.5.34

После обновления убедитесь, что и установленные исходники, и Docker-образ содержат новые функции:

```bash
cat /opt/vps-bill/current/VERSION
grep -Fn 'Проверить доступность сейчас' /opt/vps-bill/current/app/ui.py
grep -Fn 'Стоимость за сутки' /opt/vps-bill/current/app/ui.py
docker exec vps-bill grep -Fn 'Проверить доступность сейчас' /app/app/ui.py
docker exec vps-bill grep -Fn 'Стоимость за сутки' /app/app/ui.py
```

Если команда ничего не выводит или завершается с ошибкой — отправьте диагностический вывод, не меняя базу вручную.
